# Лабораторная работа №5 — Введение в Vue 3

Учебное одностраничное приложение с семью интерактивными заданиями на Vue 3. В работе показаны Options API и Composition API, реактивное состояние, директивы, события, списки, формы, вычисляемые свойства, наблюдатели и жизненный цикл компонента.

## Автор

Улискин Даниил Евгеньевич, группа ФИТ-241.

## Реализованные задания

- приветствие с двусторонней привязкой данных;
- реактивный счётчик;
- условный рендеринг;
- вывод списка через `v-for`;
- мини-форма с добавлением записей;
- квадрат и куб числа через `computed`;
- часы с `watch`, `onMounted` и приветствием по времени суток.

## Запуск

Сборка и установка зависимостей не требуются: Vue 3 подключается через CDN.

Для локального запуска откройте каталог проекта через статический сервер:

```bash
npx serve .
```

После этого перейдите по адресу, который появится в терминале. Для работы страницы требуется подключение к интернету, чтобы браузер загрузил Vue 3 с CDN.
