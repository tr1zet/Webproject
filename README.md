# Лабораторная работа №7 — Pinia, маршруты и учебная авторизация

Многостраничное To‑Do-приложение на Vue 3 и Vite. Пользователь может создать учебный аккаунт, войти, работать со своим личным списком задач и выйти для проверки другого аккаунта. Состояние пользователей и задач организовано через Pinia и сохраняется в `localStorage`.

Улискин Даниил Евгеньевич, группа ФИТ-241.

## Возможности

- регистрация с проверкой формата email, длины и совпадения паролей, уникальности пользователя;
- вход, выход и восстановление текущего сеанса после перезагрузки;
- отдельные задачи для каждого зарегистрированного пользователя;
- добавление, редактирование, удаление, поиск и завершение задач;
- четыре маршрута: вход, регистрация, задачи и «О приложении»;
- защита маршрута задач навигационным guard;
- светлая и тёмная темы, адаптивный интерфейс и управление с клавиатуры.

## Архитектура

- `useUserStore` хранит зарегистрированных пользователей и идентификатор текущего пользователя, выполняет регистрацию, вход и выход.
- `useTodoStore` хранит задачи с устойчивым `userId` и предоставляет операции только для задач текущего пользователя.
- `pinia-plugin-persistedstate` сохраняет оба стора в `localStorage` и восстанавливает их после перезагрузки.
- Vue Router использует hash-history, поэтому прямые ссылки на страницы работают на GitHub Pages без серверных перенаправлений.

## Установка и запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run dev
```

После запуска откройте адрес, который выведет Vite, обычно `http://127.0.0.1:5173/Webproject/`.

## Production-сборка

```bash
npm run build
npm run preview
```

Каталоги `node_modules/` и `dist/` являются служебными и не входят в репозиторий.

## Как проверить пользователей и личные задачи

1. Откройте страницу регистрации и создайте аккаунт с вымышленным email и учебным паролем.
2. Войдите, добавьте несколько задач и завершите одну из них.
3. Нажмите «Выйти», зарегистрируйте второй аккаунт и войдите под ним — задачи первого пользователя не должны отображаться.
4. Вернитесь в первый аккаунт и убедитесь, что его задачи сохранились.
5. Выйдите и откройте маршрут `#/tasks` напрямую — приложение должно перенаправить на страницу входа.

> [!WARNING]
> Авторизация полностью учебная и работает без сервера. Пользователи, пароли и задачи доступны в `localStorage`; это не защита настоящих данных. Используйте только вымышленные адреса и пароли, которые нигде больше не применяются.
