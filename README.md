# Accessible To-Do List — Tailwind CSS

Адаптивное приложение для управления задачами на HTML5, Tailwind CSS v4 и vanilla JavaScript. Задачи можно добавлять, редактировать, удалять, искать и отмечать выполненными. Список сохраняется в `localStorage`.

## Возможности

- добавление и редактирование задач в нативном модальном окне;
- удаление, поиск и отметка выполнения;
- автоматическое перемещение выполненных задач вниз списка;
- сохранение состояния после перезагрузки;
- управление с клавиатуры и поддержка вспомогательных технологий;
- адаптивный интерфейс для мобильных и настольных устройств.

## Установка и сборка

Требуется Node.js 20 или новее.

```bash
npm install
npm run build
```

Собранные стили появятся в `dist/css/main.css`.

## Запуск для разработки

В первом терминале запустите автоматическую сборку Tailwind CSS:

```bash
npm run tailwind:dev
```

Во втором терминале запустите локальный сервер из корня проекта, например:

```bash
npx serve .
```

Откройте адрес, который покажет сервер. Не открывайте `index.html` напрямую: для корректной проверки используйте локальный HTTP-сервер.

## Проверка production-сборки

```bash
npm install
npm run build
npx serve .
```

Каталог `dist/` является результатом сборки и не хранится в репозитории.
