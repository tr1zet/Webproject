# Лабораторная работа №8 — Основы TypeScript

Консольный практикум из девяти задач на TypeScript для Node.js. В работе используются перегрузки функций, кортежи, перечисления, функции-сторожи, обобщения, `reduce`, классы, utility types, условные и сопоставленные типы.

## Автор

Улискин Даниил Евгеньевич, группа ФИТ-241.


## Установка и проверка

```bash
npm ci
npm run check
npm run build
```

Для запуска интерактивного меню выполните:

```bash
npm start
```

В меню можно выбрать задание от `1` до `9`, ввести `a` для последовательного запуска всех заданий или `0` для выхода.

Для запуска отдельной задачи после сборки укажите её номер:

```bash
node dist/task1.js
node dist/task2.js
# ...
node dist/task9.js
```


## Состав практикума и ожидаемые результаты

1. `src/task1.ts` — форматирует число до двух знаков, обрезает строку и выводит дату в ISO-формате; показаны все три перегрузки.
2. `src/task2.ts` — преобразует цвета RGB в hex, выводит данные трёх значений `ColorName` и перехватывает `RangeError` для неверных каналов.
3. `src/task3.ts` — проверяет значения типа `unknown` на UUID, выводит профиль для корректного идентификатора и сообщения для неверной строки и числа.
4. `src/task4.ts` — добавляет, удаляет и объединяет теги без изменения исходных массивов; сравнение учитывает регистр.
5. `src/task5.ts` — запускает типизированный pipeline с одним, двумя и тремя шагами.
6. `src/task6.ts` — через `reduce` считает суммы `paid` и `free`; для пустого массива выводит нули.
7. `src/task7.ts` — разбивает числа и строки на блоки, обрабатывает остаток и пустой массив, перехватывает `RangeError` для пяти неверных размеров.
8. `src/task8.ts` — демонстрирует CRUD класса `MemoryRepository<Book>`, ошибку повторного `id` и операции с отсутствующей записью.
9. `src/task9.ts` — рекурсивно замораживает вложенный объект и массив, проверяет каждый уровень через `Object.isFrozen()`.
