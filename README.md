# Лабораторная работа №6 — To-Do List на Vue 3

Адаптивное приложение для управления задачами на Vue 3, Vite и Sass. Задачи можно добавлять, редактировать, удалять, искать и отмечать выполненными. Список задач и выбранная тема сохраняются в `localStorage`.

## Возможности

- добавление и редактирование задач в нативном модальном окне;
- удаление, поиск и отметка выполнения;
- автоматическое перемещение выполненных задач вниз списка;
- светлая и тёмная темы с сохранением выбора;
- восстановление данных после перезагрузки и безопасная обработка повреждённого `localStorage`;
- управление с клавиатуры, возврат фокуса и поддержка вспомогательных технологий;
- адаптивный интерфейс для мобильных и настольных устройств.

## Структура и средства Vue

Состояние задач, поисковый запрос и тема находятся в `App.vue`. Интерфейс разделён на компоненты поиска, переключателя темы, списка, отдельной задачи и модального окна. Данные передаются дочерним компонентам через `props`, а пользовательские действия возвращаются в родительский компонент через `emit`.

- `computed` формирует отсортированный и отфильтрованный список, число выполненных задач и текст счётчика.
- `watch` сохраняет изменения задач в `localStorage`, а также применяет и сохраняет выбранную тему. Это побочные эффекты реактивных изменений, поэтому они отделены от вычисляемых значений.
- `v-if` показывает список только при наличии подходящих задач; иначе выводит состояние пустого списка или отсутствия результатов поиска. В модальном окне `v-if` также управляет сообщением проверки поля.

## Установка и запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run dev
```

Vite выведет адрес локального сервера в терминале.

## Production-сборка

```bash
npm run build
npm run preview
```

Команда `npm run build` создаёт каталог `dist/`, а `npm run preview` запускает локальную проверку готовой сборки. Каталоги `node_modules/` и `dist/` не хранятся в репозитории.
