# Лабораторная работа №9 — To‑Do на TypeScript

Многостраничное To‑Do-приложение на Vue 3, Vite и TypeScript. Пользователь может создать учебный аккаунт, войти, работать со своим личным списком задач и вернуться к сохранённым данным после перезагрузки. Код проверяется через `vue-tsc`, TypeScript, ESLint и Prettier перед каждой production-сборкой.

## Возможности

- регистрация с проверкой email, пароля и уникальности пользователя;
- вход, выход и восстановление текущего сеанса;
- отдельный список задач для каждого зарегистрированного пользователя;
- добавление, редактирование, удаление, поиск и завершение задач;
- модальное окно создания и редактирования задачи;
- четыре страницы: вход, регистрация, задачи и «О приложении»;
- защита страницы задач с перенаправлением гостя на вход;
- светлая и тёмная темы;
- адаптивный и доступный интерфейс с управлением с клавиатуры;
- восстановление данных, созданных в лабораторной №7.

## Технологии и структура

- Vue 3 и Vite;
- TypeScript в строгом режиме;
- Pinia и `pinia-plugin-persistedstate`;
- Vue Router с hash-history;
- SCSS;
- ESLint в формате flat config;
- Prettier.

Общие модели пользователя и задачи находятся в `src/types/`, состояния — в `src/stores/`, маршруты — в `src/router/`, страницы — в `src/pages/`, а переиспользуемые элементы интерфейса — в `src/components/`.

## Требования

Проверено с Node.js 24.13.0 и npm 11.6.2.

## Установка и запуск

```bash
npm ci
npm run dev
```

После запуска откройте адрес, который выведет Vite, обычно `http://127.0.0.1:5173/Webproject/`.

## Проверки и автоисправление

```bash
npm run type-check
npm run lint
npm run format:check
npm run check
```

Команда `type-check` запускает `vue-tsc` для TypeScript-кода, Vue-компонентов и шаблонов, затем обычный `tsc` для `vite.config.ts`. Команда `check` последовательно выполняет проверку типов, ESLint и проверку форматирования, не изменяя файлы.

Для явного применения автоматических исправлений доступны отдельные команды:

```bash
npm run lint:fix
npm run format
```

## Сборка и preview

```bash
npm run build
npm run preview
```

`build` сначала выполняет полный `check` и только после успешных проверок запускает Vite. Проверка типов ищет несоответствия в исходном коде и шаблонах, а Vite преобразует модули и собирает оптимизированные файлы приложения. Сама сборка Vite не заменяет `vue-tsc` и `tsc`.

Каталоги `node_modules/` и `dist/` являются служебными и не входят в репозиторий.

> [!WARNING]
> Авторизация полностью учебная и работает без сервера. Пользователи, пароли и задачи доступны в `localStorage`. Используйте только вымышленные адреса и пароли, которые нигде больше не применяются.
